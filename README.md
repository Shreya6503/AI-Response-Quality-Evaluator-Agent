# AI Response Quality Evaluator Agent

A Streamlit app for evaluating AI-generated responses, with single-response and batch CSV evaluation options.

## Run locally

1. Install Python.
2. Clone the repository and open a terminal in the project folder.
3. Install the project dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Start the app:

   ```powershell
   streamlit run main.py
   ```

Streamlit will print a local URL to open in your browser.
